# DM Automation

ระบบตอบคอมเมนต์และส่ง DM อัตโนมัติสำหรับ **Facebook Page** และ **Instagram** ที่ติดตั้งใช้เอง (แทน ManyChat) พร้อมหน้าดูสถิติ — **ไม่ต้องเขียนโค้ด**

- มีคนคอมเมนต์คำที่กำหนด (เช่น "สนใจ") → ระบบ**ตอบคอมเมนต์** + **ส่ง DM** ให้คนนั้นทันที
- มีคนทักแชทด้วยคำที่กำหนด (เช่น "ราคา") → ระบบตอบกลับในแชทเอง
- ลิงก์ใน DM นับได้ว่ามีคนกดกี่คน
- หน้าสถิติ: ข้อความเข้า, ตรงกฎ, ส่งสำเร็จ, % อ่าน, % คลิก, ลูกค้าใหม่, กราฟรายวัน

ค่าใช้จ่าย: ประมาณ **$5/เดือน** (ค่าเซิร์ฟเวอร์ Railway) ส่วนของ Meta ใช้ฟรี

---

## สิ่งที่ต้องมี

1. **Facebook Page** ที่คุณเป็นแอดมิน
2. **Instagram แบบมืออาชีพ** (ธุรกิจหรือครีเอเตอร์) ที่**ผูกกับเพจนั้นแล้ว**
3. บัญชี **GitHub** (มีแล้ว — คือที่เก็บระบบนี้)
4. บัญชี **Railway** สำหรับเปิดระบบให้ออนไลน์ตลอด 24 ชม.

---

## ขั้นตอนที่ 1 — เปิดระบบบน Railway (ประมาณ 10 นาที)

1. เข้า [railway.com](https://railway.com) → **Login** → เลือก **Login with GitHub** (ใช้บัญชี GitHub เดียวกับที่เก็บระบบนี้)
2. กด **New Project** → **Deploy from GitHub repo**
   - ถ้าไม่เห็นชื่อ `Dm-Automation` ให้กด **Configure GitHub App** แล้วอนุญาตให้ Railway เข้าถึง repo นี้
   - เลือก `Dm-Automation`
3. ในหน้าโปรเจกต์ กด **+ Create** (หรือ **+ New**) → **Database** → **PostgreSQL** (นี่คือที่เก็บข้อมูล)
4. คลิกกล่องของ**แอป** (กล่องชื่อ Dm-Automation ไม่ใช่กล่อง Postgres) → แท็บ **Variables** → **+ New Variable**
   - ชื่อ: `DATABASE_URL`
   - ค่า: `${{Postgres.DATABASE_URL}}`
   - กด **Add** แล้วกด **Deploy** (ปุ่มสีม่วงด้านบน)
5. ยังอยู่ที่กล่องแอป → แท็บ **Settings** → หัวข้อ **Networking** → กด **Generate Domain** (ถ้าถามพอร์ต ให้ใช้ค่าที่ระบบแนะนำ)
6. รอจนสถานะเป็น **Active/Success** (2–5 นาที) แล้วกดลิงก์ที่ได้ เช่น `https://dm-automation-production.up.railway.app`

> Railway ให้ทดลองใช้ฟรีช่วงแรก หลังจากนั้นต้องเพิ่มบัตรเพื่อใช้แพ็กเกจ Hobby ($5/เดือน)

## ขั้นตอนที่ 2 — ตั้งค่าในระบบ (ทำตามหน้าจอ)

1. เปิดลิงก์จากขั้นตอนที่ 1 → ระบบจะให้**ตั้งรหัสผ่าน** (ทำทันทีหลังเปิดระบบครั้งแรก)
2. ระบบจะพาไปหน้า **คู่มือตั้งค่า** ซึ่งบอกทีละขั้นว่าต้องกดอะไรในเว็บของ Meta พร้อมปุ่มคัดลอกค่าที่ต้องใช้ และ**ติ๊กถูกให้เองเมื่อแต่ละขั้นเสร็จ**:
   1. ระบบออนไลน์แล้ว
   2. สร้างแอปใน Meta for Developers แล้วใส่ App ID / App Secret
   3. ตั้ง Webhook
   4. เชื่อมต่อ Facebook Page และ Instagram
   5. สร้างกฎอัตโนมัติอันแรก
   6. ทดสอบ
   7. ยื่น App Review เพื่อเปิดใช้งานกับลูกค้าทุกคน (Meta ใช้เวลาตรวจหลายวันถึงหลายสัปดาห์)

> ระหว่างที่ยังไม่ผ่าน App Review ระบบจะตอบได้เฉพาะบัญชีที่มีชื่อในแอป (บัญชีของคุณเองและเพื่อนที่เพิ่มเป็น Tester) — เป็นกฎของ Meta

## การอัปเดตระบบ

เมื่อมีเวอร์ชันใหม่ใน GitHub, Railway จะอัปเดตให้อัตโนมัติ ข้อมูล กฎ และสถิติเดิมยังอยู่ครบ

---

## วิธีใช้งาน

### กฎอัตโนมัติ
- **ทำงานเมื่อ**: คอมเมนต์ใต้โพสต์ หรือ ทักแชท (DM)
- **วิธีจับคำ**: *มีคำนี้อยู่ในข้อความ* (แนะนำ เหมาะกับภาษาไทย), *ตรงทั้งข้อความ*, หรือ *ทุกข้อความ*
- **ตอบคอมเมนต์**: ใส่หลายแบบได้ บรรทัดละ 1 แบบ ระบบจะสุ่มใช้ เพื่อไม่ให้ดูเป็นสแปม
- **ข้อความ DM**: ใช้ `{name}` แทนชื่อลูกค้า และ `{link}` แทนลิงก์
- **ตอบคนเดิมแค่ครั้งเดียวต่อโพสต์**: กันส่ง DM ซ้ำเมื่อคนเดิมคอมเมนต์หลายครั้ง
- **ลำดับความสำคัญ**: ถ้าข้อความตรงหลายกฎ ระบบใช้กฎที่เลขน้อยที่สุดเพียงกฎเดียว

### ความหมายของสถิติ
| ตัวเลข | ความหมาย |
|---|---|
| ข้อความเข้า | คอมเมนต์ + DM ทั้งหมดที่ระบบได้รับ |
| ตรงกับกฎ | จำนวนครั้งที่ข้อความตรงกับกฎ (ระบบลงมือทำงาน) |
| ส่ง DM สำเร็จ | DM ที่ส่งออกไปแล้ว (ส่วนที่ล้มเหลวดูสาเหตุได้ที่หน้ากิจกรรม) |
| อัตราการอ่าน | % ของ DM ที่ลูกค้าเปิดอ่าน |
| อัตราการคลิก | % ของลิงก์ที่ส่งไปแล้วมีคนกดอย่างน้อย 1 ครั้ง |
| ลูกค้าใหม่ | คนที่คุยกับเพจ/ได้รับ DM จากระบบเป็นครั้งแรกในช่วงเวลานั้น |

---

## ข้อจำกัดของแพลตฟอร์ม (กำหนดโดย Meta ไม่ใช่ระบบนี้)

- DM จากคอมเมนต์ส่งได้ **1 ข้อความต่อ 1 คอมเมนต์** และต้องส่ง**ภายใน 7 วัน** จึงควรใส่ข้อมูลทั้งหมดไว้ในข้อความเดียว
- ส่งข้อความหาลูกค้าได้ภายใน **24 ชั่วโมง** หลังลูกค้าทักมาล่าสุด
- Instagram จำกัดจำนวน DM อัตโนมัติต่อชั่วโมง ระบบตั้งไว้ 180/ชม. ข้อความที่เกินจะ**รอคิวส่งในชั่วโมงถัดไป ไม่หาย**
- ถ้า Meta ขัดข้องชั่วคราว ระบบจะลองส่งใหม่ให้อัตโนมัติ

## แก้ปัญหา

| อาการ | ตรวจอะไร |
|---|---|
| เปิดลิงก์แล้วขึ้นว่า "ยังไม่ได้เชื่อมฐานข้อมูล" | ทำขั้นตอนที่ 1 ข้อ 3–4 ให้ครบ |
| คอมเมนต์/ทักแชทแล้วไม่มีอะไรขึ้นในหน้ากิจกรรม | ดูกล่อง **Webhook ล่าสุดที่ได้รับ** ในหน้ากิจกรรม ถ้าว่าง = Meta ยังไม่ส่งมา → ตรวจขั้นที่ 3 ในคู่มือว่ากด Subscribe ครบทุกแถว และบัญชีที่ใช้ทดสอบมีชื่อในแอป |
| มีรายการ "คอมเมนต์ใหม่" แต่ไม่ส่ง DM | ข้อความตรงกับ keyword และโพสต์ที่เลือกไว้หรือไม่ และกฎเปิดอยู่หรือเปล่า |
| "ส่ง DM ไม่สำเร็จ" | ดูสาเหตุที่เขียนไว้ในหน้ากิจกรรม |
| DM ของ Instagram ไม่เข้า | เปิด **อนุญาตการเข้าถึงข้อความ** ในแอป Instagram (คู่มือขั้นที่ 4) |
| เพจขึ้นว่า "ต้องเชื่อมต่อใหม่" | ทำคู่มือขั้นที่ 4 ซ้ำ (เกิดได้เมื่อเปลี่ยนรหัส Facebook หรือรหัสฐานข้อมูล) |
| ลืมรหัสผ่าน | ใน Railway เพิ่ม Variable `ADMIN_PASSWORD` เป็นรหัสใหม่ แล้วกด Deploy |

## สำหรับนักพัฒนา

```bash
npm install
cp .env.example .env.local   # ต้องมี PostgreSQL
npm run dev                  # http://localhost:3000
npm test                     # unit + integration tests (ใช้ฐานข้อมูลจริงจาก TEST_DATABASE_URL)
npm run lint && npm run typecheck
```

ค่าตั้งค่าทั้งหมดตั้งผ่าน environment variable ได้ด้วย (ดู `.env.example`) ถ้าตั้งไว้จะใช้แทนค่าที่กรอกในหน้าเว็บ
ทดสอบ webhook จาก Meta บนเครื่องตัวเองได้ด้วย tunnel เช่น `cloudflared tunnel --url http://localhost:3000`

**โครงสร้างหลัก**

```
src/app/api/webhooks/meta/route.ts   รับ webhook → ตรวจลายเซ็น → ใส่คิว
src/lib/meta/webhook.ts              แปลง payload ของ Meta เป็นงาน (comment / dm / read)
src/lib/automation/handlers.ts       หา rule → ตอบคอมเมนต์ / ส่ง DM / บันทึกสถิติ
src/lib/queue/                       คิวงานบน Postgres + worker (ลองใหม่, คุมลิมิตต่อชั่วโมง)
src/lib/config.ts                    ค่าตั้งค่าที่กรอกผ่านหน้าเว็บ (ตาราง settings)
src/lib/rules/match.ts               ตรรกะจับ keyword
src/lib/stats.ts                     คำนวณสถิติหน้าภาพรวม
src/app/r/[code]/route.ts            ลิงก์ติดตามการคลิก
src/app/(dashboard)/                 หน้าแดชบอร์ด (guide = คู่มือตั้งค่า)
src/db/schema.ts + drizzle/          ตารางฐานข้อมูล (แก้ schema แล้วรัน npm run db:generate)
```
